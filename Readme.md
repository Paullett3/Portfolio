This is My Portfolio.
This project is a personal portfolio website for Paullette Ndungu, a software engineering student. It is designed to showcase her skills, projects, and learning journey. The website is built with semantic HTML5 and styled with a custom CSS stylesheet.
Two-Column Layouts: Uses CSS Flexbox to create side-by-side "invisible boxes" for:

The Home image and the About Me text.

The My Work and My Skills sections.

Media Content: Includes an embedded audio file (<audio>) to share a "coding philosophy."

Skills Table: A clear <table> displaying technical skills and experience levels.

Contact Form: A functional HTML <form> for visitors to send messages.

Custom Fonts: Uses Google Fonts (Roboto) for clean, modern typography.
